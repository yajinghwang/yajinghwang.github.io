## Course Overview

This course introduces Natural Language Processing (NLP) methods and their applications in social science research, combining theoretical foundations with hands-on Python programming for textual data analysis.

Topics covered include text preprocessing and data cleaning, sentence segmentation, tokenization, part-of-speech tagging, lemmatization, dependency parsing, word embeddings, and sentiment analysis, using tools such as spaCy, Gensim, and jieba.
